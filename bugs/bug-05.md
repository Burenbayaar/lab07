# BUG-05: POST /api/books буруу JSON биетэй хүсэлтэд 400-ийн оронд 200 OK буцаадаг

Орчин: Уншлагын жагсаалт v2.0, curl, Ubuntu 24.04, 2026-10-20

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Терминалд `node app.js` ажиллуулна
2. Өөр терминалд дараах командыг ажиллуулна:
   `curl -i -X POST localhost:3000/api/books -d 'буруу оролт'`
3. Хариуны статусын мөр болон биеийг харна

Хүлээгдэж байсан: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана.»

Бодит үр дүн: `HTTP/1.1 200 OK`, бие нь `{"result":"OK"}` — сервер буруу оролтыг амжилттай гэж хүлээн авсан.

Ноцтой байдал: Major — клиент алдааг илрүүлэх боломжгүй; буруу өгөгдөл хүлээн авагдаж, өгөгдлийн бүрэн бүтэн байдал алдагдах эрсдэлтэй.
