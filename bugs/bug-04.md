# BUG-04: Хайлтын хажуугийн товч дээр үсгийн алдаа — «Бугд» (зөв нь «Бүгд»)

Орчин: Уншлагын жагсаалт v2.0, Firefox, Ubuntu 24.04, 2026-10-19

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Браузераар http://localhost:3000 нээнэ
2. «Хайх» товчийн баруун талын товчны бичвэрийг уншина

Хүлээгдэж байсан: «Үйлдэл бүрийн дараах мессеж тухайн үйлдэлдээ тохирно; текстүүд үсгийн алдаагүй.» — «Бүгд».

Бодит үр дүн: Товч дээр «Бугд», хайлтын талбарын placeholder дээр «Хайх уг» гэж бичигдсэн (ү үсгийн оронд у).

Ноцтой байдал: Cosmetic — үйл ажиллагаанд нөлөөгүй ч аппын мэргэжлийн төрхийг бууруулна.
