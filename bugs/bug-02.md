# BUG-02: «Устгах» товч улаан биш, ногоон өнгөтэй

Орчин: Уншлагын жагсаалт v2.0, Firefox, Ubuntu 24.04, 2026-10-19

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Браузераар http://localhost:3000 нээнэ
2. Хүснэгтийн мөр бүрийн баруун талын «Устгах» товчийг харна

Хүлээгдэж байсан: «Аюултай үйлдлийн товч (Устгах) улаан өнгөтэй.»

Бодит үр дүн: Гурван мөрийн «Устгах» товч бүгд ногоон өнгөтэй.

Ноцтой байдал: Minor — ногоон өнгө «аюулгүй / баталгаажуулах» гэсэн утгатай тул хэрэглэгч буцаагдашгүй устгах үйлдлийг санамсаргүй хийх эрсдэлтэй.
