# BUG-03: «Нийт ном» тоолуур хүснэгтийн мөрийн тооноос 1-ээр их (4 ≠ 3)

Орчин: Уншлагын жагсаалт v2.0, Firefox, Ubuntu 24.04, 2026-10-19

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Браузераар http://localhost:3000 нээнэ
2. Хүснэгт дэх номын мөрийг тоолно (3 мөр)
3. Хүснэгтийн доорх «Нийт ном» тоог харна

Хүлээгдэж байсан: «"Нийт ном" тоолуур хүснэгтэд буй номын тоотой тэнцүү.» — 3 байх ёстой.

Бодит үр дүн: «Нийт ном: 4 · Хамгийн шинэ он: 2008» гэж харагдана.

Ноцтой байдал: Major — хэрэглэгчид буруу тоон мэдээлэл харуулж байна; апп ажиллаж эхэлмэгц, ямар ч үйлдэлгүйгээр илэрнэ.
